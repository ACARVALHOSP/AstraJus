# Especificação: identidade visual Carbon

Registrada em: 2026-10-29
Escopo: frontend AstraJus, branch `astrajus-react`.
Referência: [Design System: AstraJus](../../DESIGN.md).

## Direção visual

Carbon white/g100, com interface sóbria e densa para trabalho jurídico. Preservar a identidade existente, conforme escolha do usuário. Hierarquia, leitura de dados e ações previsíveis orientam a composição.

## Colors

Azul interativo para ações e seleção; superfícies brancas e cinza claro, texto escuro e divisores discretos. Os tokens semânticos Carbon são a referência para os estados. O toggle no shell alterna Claro (white) e Escuro (g100), com preferência local compartilhada pelas páginas do frontend. O frontmatter de `DESIGN.md` descreve a base white; g100 usa os tokens oficiais do CSS Carbon, sem inversão de cores.

## Elevation & Depth

Superfícies predominantemente planas. Camadas e divisores organizam o conteúdo.

## Shapes

Controles e tabelas seguem a geometria Carbon.

## Aplicação

Estas diretrizes orientam futuras alterações do frontend. Este registro é documental e não altera a interface.
