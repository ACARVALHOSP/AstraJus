# Identidade no shell

Exibir o nome do usuário autenticado na barra superior, com painel de nome completo, login, nível de acesso, configurações de acesso e Sair. Nome longo truncado; celular com ícone oficial Carbon e rótulo acessível. Perfil obtido por GET /responsaveis/me, com autenticação e Cache-Control: no-store. Sem persistir perfil no navegador.

Prévia aprovada pelo usuário em 30/10/2026.
